# Принятые решения (append-only)

Журнал решений с обоснованием — чтобы не пересматривать их заново и не
восстанавливать «почему так» из git-археологии. Формат: дата, решение,
почему, ссылка на детали. Новые записи добавляются в конец секции.

## Safety

- **2026-06-10 — `panic_immediate_abort` ЗАПРЕЩЁН.** Дропнул бы ~8 КБ
  panic-строк, но обходит `#[panic_handler]` — то есть gate-kill в
  safety.rs. Безопасность мотора важнее флеша. [flash-size.md → Dead ends]
- **2026-06-11 — `CordicSinCos` паникует на неинициализированном CORDIC —
  это намеренный fail-fast.** Никаких libm-фолбэков: тихая деградация в
  ISR хуже громкого падения на бринг-апе.
- **2026-06-11 — дефолтная failsafe-политика `ControlledStop` + терминал
  `ParkBrake`.** Лонгборд: потеря линка = плавное regen-торможение до
  остановки, затем замыкание обмоток (держит на уклоне без энергии).
  Re-arm защёлка снимается только явным Stopped/Coast/Brake. [safety.md]
- **2026-06-11 — hall staleness: фиксированный таймаут-backstop НЕ
  ДОБАВЛЯТЬ (won't-fix).** Стоячий ротор легитимно не даёт эджей; backstop
  объявлял бы холлы мёртвыми на каждой остановке → open-loop override у
  светофора. Мёртвый-на-стоянке сенсор по эджам принципиально неотличим от
  стоящего ротора; обрыв кабеля ловится invalid-state (pull-up → 0b111),
  движение покрывает скоростно-адаптивный путь `is_stale_at_speed`.
- **2026-06-12 — bus current limits: `< 0` = выключено (дефолт), `0` =
  полный запрет, иначе амперы.** `bus_regen_max_a = 0` — штатный
  ЛБП-безопасный режим; ControlledStop при этом сам деградирует в coast
  через no-progress watchdog, windings-short Brake шину не трогает.

## Прошивка / платформа

- **2026-06-11 — g431 по умолчанию baked-config профиль.** Runtime-flash
  персистентность стоила −25.5 КБ (config-server + sequential-storage +
  postcard-кодеки). Workflow: detect → live-тюнинг → `config dump --rust`
  → rebuild. [flash-size.md]
- **2026-06-12 — g431 storage-профиль УДАЛЁН СОВСЕМ.** Detection-фиксы
  переполнили 124K-лейаут; вместо диеты резервного профиля плата отдала
  персистентность навсегда: один memory.x на 128K, конфиг только baked,
  config-server RAM-backed (persist-capable = false). f405/g474 хранят
  как раньше. [flash-size.md, коммит 7a6c923]
- **2026-06-11 — никакого libm-trig в firmware-достижимом коде** (5 КБ
  флеша + ~6200 циклов из-за `-fp64`-softfloat в rem_pio2f). Только
  SinCos-бэкенды (CORDIC/FastSinCos) и fast_math. [flash-size.md → Rules]
- **2026-06-11 — rc_w0 статус-регистры: только complement-mask запись
  (`clear_rc_w0!`), `modify` запрещён** (LDR+BIC+STR теряет флаг,
  выставленный между чтением и записью). Для rc_w1 паттерн
  ПРОТИВОПОЛОЖНЫЙ — макрос там запрещён. [register-access.md]
- **2026-06-11 — двухпрошивочный detect/run сплит ОТКЛОНЁН** (пока):
  detect-образ ⊇ run-образа без core-гейтов на run-only подсистемы —
  перестал бы влезать раньше. Лестница резервов в flash-size.md.
- **2026-06-12 — детекция: q-axis flux метод понижен до диагностики.**
  В open loop смещён на cos(load angle) до −98%; продакшн — back-EMF-vector
  (magnitude), spin-down — только при наличии coast-телеметрии.
  Метод-лестницы (`measure_*_auto`) едины для полной и пошаговой детекции.
- **2026-06-11 — F405: блокирующий erase 128 КБ-сектора (~0.5 с) принят
  как known residual.** TOCTOU закрыт Busy-гейтом (мотор гарантированно
  остановлен на время записи), IWDG-маржин — бэкстоп. Не чиним, пока не
  мешает.
- **2026-06-12 — конвенция hall-калибровки: таблица хранит ЦЕНТРОИДЫ**
  (то, что меряет sin/cos-усреднение `HallCalibrator`), интерполяция
  якорится на ГРАНИЦУ = середину соседних центроидов (VESC-style).
  Ширины секторов не хранятся — середины измеренных центроидов поглощают
  асимметрию установки. `VirtualMotor` центрирует сектор k на
  `k·60° + hall_offset` — той же конвенции. [notes/hall-improvements.md,
  коммит 9f936bb]

- **2026-06-12 — HFI: «маржин для ограниченного, гейт для неограниченного».**
  Демод HFI без несущей меряет тишину → update() и инжекция включаются
  только парой (`hfi_active()`): в не-Hfi источниках — никогда (~10%
  бюджета ISR обратно в дефолтном hall-конфиге), в Hfi-источниках выше
  кроссовер-защёлки — выключены, с **преднагревом** на один
  гистерезисный band выше порога снятия защёлки (демоду нужно несколько
  периодов несущей на lock; `restart_demod()` на резюме — иначе stale
  фильтры маскируются под confidence). Маржин сознательно НЕ сайзится
  под механически-неограниченное торможение (клин пробивает любую
  конечную полосу мгновенно) — этот хвост закрывает trust-гейт: холодный
  демод = confidence 0 = `angle_trustworthy()` false = iq зарезан на
  миллисекунды лока у почти-нуля скорости. Та же философия, что у
  deadman («не гарантируй доставку — убери положительное
  подтверждение»). Оба случая закреплены closed-loop тестами
  (controller-bounded рампа: lock-before-weight; клин: гейт держит до
  релока). Из диалога с Opus 4.8.
- **2026-06-12 — feature-флаг для рантайм-HFI НЕ делать** (предложение
  Opus 4.8 отклонено): флаг покупал только флеш, которого после удаления
  g431-storage хватает (17+ КБ), ISR-цена ушла гейтом выше, а цена —
  cfg-шум в менеджере + ещё одна CI-конфигурация. Если флеш снова
  прижмёт — строка в резервной лестнице flash-size.md.
- **2026-06-12 — амплитуда несущей HFI выводится из измеренной L**
  (`V = I_target·ω_c·L`, потолок — старый vbus-ratio): сырые 12.5%·vbus
  на низкоиндуктивном аутраннере (25 µH Flipsky) дали бы десятки ампер
  риппла. Та же логика, что адаптивная амплитуда детекции.

- **2026-06-12 — лимиты тока: слоёная схема «рейтинг мотора / операционные».**
  Рейтинг (продолжительный тепловой ток `√(P_loss/R/1.5)` — VESC-формула
  i_max, мы её уже считали в детекции и выбрасывали) — свойство МОТОРА,
  персистится в группе MotorParams вместе с классом рассеяния (W).
  Операционные лимиты (CurrentLimits) — свойство сессии/установки; при
  применении клампятся: `effective = min(операционный, рейтинг, плата)`,
  OC-трип ≤ 1.5×рейтинга (VESC `l_abs_current_max`), unset-операционный
  дефолтится в сам рейтинг. В отличие от VESC, юзер не может разрешить
  мотору больше, чем тот терпит. Bus-лимиты НЕ в конфиге мотора — они
  свойство питания (ЛБП/батарея). HFI-цель риппла масштабируется от
  РЕЙТИНГА (0.15×, кап 2 А), не от операционного лимита: стендовый кап
  iq не должен душить SNR несущей. Blob MotorParams вырос — старая
  запись на f405/g474 упадёт в дефолты, перезаписать группу один раз.

## Виртуальный мотор / тесты

- **2026-06-10 — новые эффекты планта только за опциональными параметрами
  с идеальным дефолтом** (паттерн `sat_k`) — существующие тесты остаются
  закреплёнными. Каждый sim-апгрейд обязан приходить с тестом, который
  падает без соответствующей компенсации. [notes/virtual-motor-fidelity.md]
- **2026-06-12 — урок hall-конвенций: спаренные конвенции сим/эстиматор
  могут взаимно сокращаться и прятать систематические смещения.** Тесты
  угловых эстиматоров обязаны сверяться с НЕЗАВИСИМОЙ непрерывной моделью
  ротора, а не с собственными хранимыми углами.
